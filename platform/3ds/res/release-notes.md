### Install or update
- Install `ac3ds.cia` with FBI (it replaces the previous version), or copy `ac3ds.3dsx` from the zip to `sdmc:/3ds/` and start it from the Homebrew Launcher.
- Your save and settings stay where they are (`sdmc:/3ds/ac3ds/`).
@FBI@

### Quick install with FBI
In FBI: **Remote Install → Scan QR Code**, then scan this code. You still need your own disc image in `sdmc:/3ds/ac3ds/`.

![QR code for FBI: installs ac3ds.cia](@QR_URL@)
@END_FBI@

### What you need
- A New 3DS, New 3DS XL or New 2DS XL with custom firmware (Luma3DS)
- **Your own** disc image of Animal Crossing (USA, GAFE01, first release): `.iso`, `.gcm` or `.ciso`. No game data is included.
- For sound: the DSP firmware dump (`sdmc:/3ds/dspfirm.cdc`)
